# RG: Taiwan 2021 as a test year (S1 and S5)

Date 2026-11-18. Review comment 6. Taiwan 2021 had 0 local dengue cases (checked against Taiwan CDC, `docs/data/zero_fill_crosscheck.md`). It was left out of the test years only because it had no cases. Here it is added back as a test year.

## What was run
- **S1** (done earlier in R2): `configs/taiwan_s1_tw2021_{L3,L4,L3_Cstar,L4_Cstar}.yaml`, C\* = C1, TW L1 params.
- **S5 (new)**: `configs/taiwan_s5_tw2021_{L3,L4,L3_Cstar,L4_Cstar}.yaml`. Each is a copy of `configs/taiwan_s5_*.yaml` (train on BR+CO+PE, BR L1 params, C\* = C3, seed 0, LST screen) with `test_years: [2021]` only. Run dirs `runs/taiwan_s5_tw2021_*`.
- Chunks are per (year, horizon), so only the 8 new 2021 chunks were fitted (h1, h4; n_train = 1,052,256). They are combined with the existing 2020/2022-24 runs. Cost 7.2 worker-h (tmux `pop_tw2021s5`, 2 workers x 4 threads, nice 19).
- Scoring: h {1, 4} pooled, DM with EWC + HLN (`pop.eval.estimands.infer_estimand`), margin 1% of WIS(L3).
  - **v3 primary** = `exclusions_v2` (no-geometry units, incomplete weeks, unit-week exclusions) + `row_filter: origin_year`, as in kit v3 / `scripts/analysis/control_panel.py`. It reproduces kit v3 T1 (TW S1 with 2021 −0.60%; TW S5 without 2021 −11.16%).
  - **legacy v1** = v1 exclusions, no row filter (the R2 numbers).
- Script `runs/taiwan_s5_tw2021_analysis/rg_tw2021.py`; all numbers in `RG_tw2021.csv`.
- `configs/primary_cells.yaml` already lists these dirs under TW S5 `add_test_years`, so kit v3 picks them up on its next run.

In 2021 every target is 0, so any upper-quantile mass is pure loss. In S5, L4 has about 3x the WIS of L3 on these rows. This matches the known S5 mechanism (`docs/results/s5_outliers_verification.md`): the Taiwan embeddings sit near hyper-endemic Colombian cities, so L4 raises the upper quantiles on zero rows. 2021 is all zero rows, so the harm is largest there. Percent-of-reference values for 2021 alone are meaningless (WIS(L3) is near 0), so only absolute values are given.

## Reading
- Adding 2021 makes both Taiwan cells more negative. No sign changes.
- **TW S1:** under v3 primary scoring it moves from "equivalent" to nominally "inferior" (p = .049; CI upper bound −0.004%). The effect is still small (−0.6%) and will not survive Holm over the family.
- **TW S5:** the harm grows from −11.2% to −17.3% of WIS(L3), with a wider CI. Part of this is a smaller denominator (2021 adds near-zero WIS(L3) rows); the absolute G_excess goes from −.0027 to −.0035 log-WIS. G_id also becomes nominally significant (C3 hurts L3).
- The conclusion is unchanged: AlphaEarth gives no gain in Taiwan, and out-of-distribution transfer (S5) is harmful. Including 2021 strengthens the harm finding.
