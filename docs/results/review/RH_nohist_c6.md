## Interpretation

The embedding gain without a control (+2.54% [-0.82, +5.89], p = 0.13) is of the same order as the gain from an identifier that carries no environmental information, which is consistent with the embedding acting at least partly as a location label in this arm; however, this is a single-seed exploratory comparison without multiplicity correction and it is not powered to separate identity from environment.
