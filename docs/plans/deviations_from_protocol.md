# Deviations from the frozen protocol (dated log)

Each row records what changed, when, why, and whether the change was made **after** seeing any test-year results. The paper reproduces this table.

**What was fixed when.** The original protocol is the evaluation plan plus the planner's response of 2026-11-15 (`docs/plans/paper1_evaluation_plan.txt`, `docs/plans/paper1_review_response.md`). Rows 1–10 were committed in `d8c7944`; rows 11–17 in `fcc3c38`, before any spatial-split (S2–S5) result was read; the no-history arm was pre-registered in `bd3ba50` before it ran; the control fixes of rows 13–15 were committed in `9de7386`. Rows 18–23 were written on 2026-11-16 before any spatial-split result was read and committed in `e9df1f1`. Rows 24–34 were written on 2026-11-18 after the external review, **after the S1, S2, S3 and S5 results (and Colombia S4) had been seen**; only Brazil S4 and the no-history cells were still running. **The temporal split S1 is partly unblinded:** Brazil, Peru and Taiwan S1 test-year results were computed and read before rows 2, 8, 9, 11, 12, 16 and 18–22. The design freeze planned for 15 January 2027 has not happened yet.

## Documented, not changed (2026-11-16; audits 3 and 4)

- **S3 buffer geometry (audit 3 M-1).** The S3 buffer is "polygon-centroid distance ≥ D". C1-matched (and C4) use representative points, so with representative points the minimum train–test distance in a few folds is below D (Brazil fold minimum 161 km vs D = 225; Colombia 122 vs 130). This is a definition, not a leak; it is stated in the paper.
- **No-history parameters (audit 3 M-4).** The no-history N-levels use Brazil's L1 parameters (127 leaves / 100 min data), tuned on a case-history model. This follows the "one parameter set per country" rule (row 2) and is disclosed.
- **Brazil per-level control selection (audit 3 M-5).** `runs/brazil_s1_controls_2019/selection.json` ranks the pre-fix C3 (per-year permutation) and C4 (8,483 km). It is reported only as part of the per-level-tuning sensitivity and is not rerun.
- **C5 look-ahead (audit 3 L-3).** C5 (static AlphaEarth 2023) gives 2020–22 targets information from a later year. This favours the control, i.e. it is conservative for the embedding claim.
- **Brazil S5 LST (audit 3 L-4).** Brazil test rows in S5 use the LST screen (`lst_screen: true`, as for the other countries in the pooled S5 model), while Brazil S1–S4 do not. Comparisons of Brazil rows across splits therefore mix two LST definitions (the screen flags 0.08/0.02% of Brazil unit-months).
- **Strata weighting (audit 4 M3).** Stratum estimates (observed, zero-filled, outbreak, …) use the same week-pooled estimator as the primary: each target week gets equal weight, however many stratum rows it has. They are not row-weighted, so they cannot be read as shares of the overall gain.
- **Bootstrap details (audit 4 M5).** The sensitivity bootstrap is a *circular* block bootstrap (Politis & Romano 1992) with 52-week blocks; with T = 209–261 weeks that is only 4–5 blocks, so its percentile CIs are coarse. Its point estimate is the row-level mean, not the primary week-pooled mean.
- **Equivalence before significance (audit 4 L1).** The effect classifier checks equivalence first, so a small but significant effect is labelled "equivalent" (e.g. Brazil G_emb 2021, p = .019). The DM p is always reported next to the class.
- **Outbreak threshold wording (2026-11-18).** The outbreak threshold is max(unit p90 of weekly cases over 2013–2019, 5). The 2013–2019 window includes the training target years 2018–2019; it contains no test year. Say "2013–2019 (pre-test years)", not "pre-training years".
